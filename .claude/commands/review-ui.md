현재 프로젝트의 UI/UX를 다음 기준으로 리뷰해줘.

## 체크 항목

### 접근성
- [ ] 버튼과 링크에 명확한 텍스트가 있는가?
- [ ] 색상 대비가 충분한가? (WCAG AA 기준)
- [ ] 키보드로 조작 가능한가?

### 반응형
- [ ] 모바일(375px) 에서 레이아웃이 깨지지 않는가?
- [ ] 텍스트가 너무 작거나 넘치지 않는가?

### UX
- [ ] 사용자 액션(버튼 클릭 등)에 피드백이 있는가?
- [ ] 빈 상태(데이터 없을 때) 처리가 있는가?
- [ ] 로딩/에러 상태가 고려되어 있는가?

### 코드 품질
- [ ] 중복 스타일이 있는가?
- [ ] 공통 클래스(.card, .btn 등)를 잘 활용하고 있는가?

## 결과 형식
각 항목에 대해 ✅ 통과 / ⚠️ 개선 필요 / ❌ 문제 있음 으로 표시하고,
개선이 필요한 항목은 구체적인 코드 수정 예시를 함께 제시해줘.
